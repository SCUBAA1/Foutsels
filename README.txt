FOUTSELS: TRUST NOBODY — SOLO 3D PLAY NOW

Open index.html in a browser with internet. For iPhone, publish this folder using Netlify Drop or another static HTTPS host, then open the resulting link in Safari and optionally use Share > Add to Home Screen.

Includes seven stylized 3D characters, five 3D map themes, eight prototype modes, bots, menu, iPhone joystick, action buttons, and chase camera.

IMPORTANT LIMITATIONS: This is a playable solo prototype, NOT the finished ultrarealistic game. No real-time online multiplayer, no public server, no full production assets or animations. Internet required to load Three.js from jsDelivr.
